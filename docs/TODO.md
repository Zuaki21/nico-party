# 今後やりたいこと

## セキュリティ: Discord でログインした人だけが使えるようにする

2026-10-31 (ver 1.4.0) に実装済み。`server/src/pass.ts` が HMAC 署名つきの通行証を発行し、WebSocket（名前の検証）、
`/nico/<通行証>/...`（中継）、`/api/search` で必須にしている。通行証ごとに中継 300 回/分・検索 30 回/分の制限がある。

### 残っている弱点
- 自分の Discord アカウントでログインして通行証を抜き出す悪用は防げない（回数制限で抑えている）
- 回数の集計は Worker の中だけ（複数のインスタンスにまたがらない）ので目安。厳密にするなら Durable Object か Rate Limiting バインディングを使う
- `/api/token` は全体で 120 回/分の制限（Discord のプロキシ経由だと接続元 IP が全員同じなので、人ごとには分けられない）
- 通行証は URL（WebSocket の `?pass=`、`/nico/<通行証>/`）に載るので、アクセスログに 24 時間有効なものが残りうる
- 上流（ニコニコ）の応答の大きさには上限がない

2026-11-01 (ver 1.7.17) に追加: 署名の鍵を `PASS_SECRET` に分離、ユーザーごとの接続数（5 本）・メッセージ量の制限、
入室しない接続の切断、チャンク転送でも効く本文サイズの上限、`ALLOW_ANON_WS` はローカル（接続元 IP が 127.0.0.1）でのみ有効。
